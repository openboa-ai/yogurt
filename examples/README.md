# Consumer examples

- [Native example](native-ui/README.md) shows a self-contained Zig and Vercel Native SDK view using the installed controls and fonts.
- [Project scenarios](project-use/scenarios.json) supply realistic work, decisions and recovery states to the [offline playbook](../playbook.html).
- [Verification fixtures](../checks/fixtures/) drive install and runtime checks in disposable consumers. Try the [basic controls](basic-controls/index.html) and [wordmark specimens](signature/index.html) in a browser.

Examples consume [catalog entries](../catalog/README.md) and renderer bindings. Shared rules live in the catalog and [design guide](../DESIGN.md).
