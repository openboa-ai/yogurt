# Agent UI bridge evidence

An isolated installed Vite consumer and an isolated installed Next.js consumer imported the explicit bridge entry. In a synthetic browser fixture, creation without a policy threw, supported controls appeared in the snapshot, allowed changes reached host state, refused changes did not, a password value was redacted and an agent-hidden field was omitted.

The fixture invokes bridge methods directly; it does not run a model or connect a service. Observation scope remains the product's responsibility. Native and production agent integration are not established.
