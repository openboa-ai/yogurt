# Agent import guidance evidence

One small-model decision-flow trial loaded the build skill and failed before the UI could mount: its answer imported `Result` from the `Status` entry. The installed lookup had supplied separate entries, but both shared a declaration file. The remaining flow assertions were not observed. The attempt took 59.669 seconds and reported 94,715 input tokens, including 75,648 cached tokens, and 2,560 output tokens. Its actual monetary charge was unavailable.

The revised lookup emits separate, copyable statements. An installed Web fixture checked six resolved statements against their actual ESM exports, rejected an unknown ID and exercised both Vite and Next.js consumers. The Native lookup returned its existing template binding. The changed skill passed frontmatter validation and sixteen deterministic evaluation tests passed. A new model-driven outcome trial is required to determine whether the guidance changes the observed behavior.
