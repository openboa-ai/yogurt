# Component usage guidance evidence

The current catalog contains usage guidance for all 125 component IDs. Each entry provides a use case, companion IDs, an unsuitable use and verification states. The existing pattern catalog remains responsible for complete task compositions. Independent comparison against implementation covered a subset, not every entry or platform.

The catalog validator checked the structure and referenced component IDs. The guide was exercised at 320 and 1440 px, including navigation from a component's usage guidance. Installed Web consumers resolved guidance from the packaged catalog and returned null when guidance was removed in a disposable fixture; this simulates the old catalog shape, rather than testing an older archive. A Native archive lookup also verified the catalog against its pinned archive and rejected a modified copy. Skill format validation passed for both updated skills.

These are deterministic checks, not evidence of model decision quality or Native visual behavior. Model evaluation remains unavailable until the evaluation environment passes its isolation preflight. Complete cross-platform guidance review and independent visual review remain open.
