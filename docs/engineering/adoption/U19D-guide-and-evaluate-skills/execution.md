## Completion

The implementation is complete when both independently pinned fixture consumers can install and exercise the candidate, an installed plugin follows the intended workflows, and the evaluation report supports keeping or changing each tested workflow. Record confirmed renderer support and retain the prior working pins. For a model decision, require repeated evidence from the evaluation protocol. Record unavailable model or pricing data explicitly and keep an inconclusive comparison open.

Record candidate implementation, local fixture verification, hosted delivery and each product's adoption when observed. The product owners decide when to change their live pins. Real issue creation uses the consumer's configured destination and authorization. The acceptance suite uses a simulated issue tracker.
