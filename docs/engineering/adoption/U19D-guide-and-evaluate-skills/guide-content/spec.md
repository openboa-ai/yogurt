- The guide, handbook, repository documentation and SDK describe Yogurt's own components, design decisions, behavior and usage. Remove the comparison page, its navigation, the catalog crosswalk and its package export. Keep first-party examples and motion guidance.
- Search the gallery by Yogurt component names, IDs and families. Keep component imports, IDs, editable recipes, tokens, native bindings, original artwork and licenses. Keep the registry format and documentation required to install or use an integration.
- Build the handbook, catalog, static site and package from the same checkout. Check that removed sources have no links, search aliases, copy steps or package entries. Verify the catalog renders and searchable components and installed controls still work. After deploy, verify the main guide and removed routes on the production site.
