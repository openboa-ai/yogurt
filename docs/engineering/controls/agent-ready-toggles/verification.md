# Toggle replacement evidence

At 320 px dark and 1440 px light, initial and selected captures for both the toggle and the group matched their prior captures byte for byte. Installed Vite and Next.js fixtures exercised single and multiple selection, deselection, disabled options, keyboard focus wrapping, ordered host values, allowed and refused agent changes and callback counts. The component and motion galleries were checked.

These observations cover Web fixtures and settled captures. Native rendering, every motion frame, independent visual approval and live product outcomes remain separate.
