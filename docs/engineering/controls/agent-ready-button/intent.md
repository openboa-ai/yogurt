# Agent-ready button intent

An independent React consumer can use the existing Yogurt button without changing its appearance, motion, labels, form behavior, or public imports. Its behavior can participate in an explicitly configured component agent using the same installed behavior runtime as the consumer. The component never creates an agent bridge or grants an agent authority by itself.

This is the first bounded slice of the owner-approved component foundation replacement. The complete replacement, native coverage, agent workflows and interactive review remain in progress.
