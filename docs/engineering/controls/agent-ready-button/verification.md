# Button replacement evidence

At the candidate revision, 320 px dark and 1440 px light guide captures matched the corresponding resting screenshots byte for byte. The five button sizes and their actions passed the existing browser check. An installed Vite and Next.js consumer exercised the shared agent bridge, policy refusal, focus through the public ref, keyboard activation, blocked and pending clicks and native form submission. Both consumers also installed a button wrapper through the Yogurt CLI and verified that an agent action reached the same shared runtime and host callback.

These observations cover Web fixtures. They do not establish a separate shadcn CLI installation, every animation frame, Native parity, an independent visual approval or release readiness.
