# Text field replacement evidence

TextField and SearchField guide captures at 320 px dark and 1440 px light matched their prior resting captures byte for byte. The existing size and guide-navigation checks passed. Installed Vite and Next.js consumers exercised controlled agent changes and host callbacks, denied changes, search clearing and focus, disabled state, native form data and reset.

These observations cover Web fixtures. They do not establish every input type, every motion state, Native parity or an independent visual approval.

In installed Vite and Next.js fixtures, an overlength agent update was refused without changing host state. An allowed update was delivered once. An existing controlled value longer than the current limit could still be shortened with the keyboard.
