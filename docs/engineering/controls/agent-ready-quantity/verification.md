# Quantity baseline evidence

Installed Vite and Next.js consumers exercised the shared increment button through the agent bridge and checked callback counts, upper bounds, disabled state and direct decrement. An unaligned starting value of 1 with a step of 2 advanced to 3, 5 and 7. The existing browser quantity check verified geometry and bounds at 320 px and 1440 px.

This is a partial transition: the buttons use shared behavior, while the quantity adapter still owns the numeric state. The dedicated numeric provider snaps to its step grid, which differs from the existing increment behavior for an unaligned value. Native rendering, complete motion parity and live product behavior remain unqualified.
