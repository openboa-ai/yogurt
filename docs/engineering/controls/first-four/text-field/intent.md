# Edit a name without losing my place

Draft intent r1. A person should always know what they are naming, what is already saved and what they can do when an entry is invalid. Typing creates a draft. Save commits that draft.

**Success.** “View name” remains visible after typing. An empty submission explains the missing name next to the field. A correction removes the error and preserves the new text and caret.

**Failure worth catching.** A delayed save replaces the second edit with the first name, or the placeholder disappears with the only explanation of the field.

The product owns validation and the committed value. Yogurt owns the label, value connection, focus and presentation of feedback. [Paired spec](spec.md) · [Shared study](../README.md)
