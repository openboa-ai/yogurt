# Save the name I just edited

Draft intent r1. A person renaming a view needs to see when a draft becomes its saved name. The button describes that single change. “Save name” leaves the immediate date preference independent.

**Success.** On release, the edited name stays readable, the action holds its place while saving, and the saved view shows the confirmed name. A second press during the same request reaches the host zero additional times.

**Failure worth catching.** A button looks finished when a timer expires while the saved record still carries its old name.

The consumer supplies the intended action, availability and confirmed outcome. Yogurt owns the appearance and activation contract. [Paired spec](spec.md) · [Shared study](../README.md)
