# Clear this draft and keep typing

Draft intent r1. A person replacing a view name should be able to clear the current text in one action. The clear sign sits inside the field because its reach ends at that value.

**Success.** Activate “Clear view name”. The draft empties, the insertion point returns to the field and the saved name stays visible beside it.

**Failure worth catching.** The icon is visually 18 px and its entire touch target is also 18 px. A missed tap or lost keyboard focus forces a second search for the field.

The product supplies an explicit action name and the target field. Yogurt owns the hit area, focus treatment and activation semantics. [Paired spec](spec.md) · [Shared study](../README.md)
