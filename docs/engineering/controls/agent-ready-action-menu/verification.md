# Action menu replacement evidence

The anchored and expanding examples matched byte for byte in closed and settled open captures at 320 px dark and 1440 px light. An automated check interrupted and reversed the expanding spring, verified its settled geometry and exercised reduced motion. The existing interaction suite passed all motion examples.

Installed Vite and Next.js consumers exercised keyboard opening and navigation, typeahead, disabled items, focus restoration, item selection and allowed and refused agent actions. The action menu uses the shared inline popup and button behaviors with a Yogurt keyboard adapter; it is not a replacement of the complete menu behavior provider. Native rendering, every animation frame, independent visual approval and a live product remain separate evidence.
