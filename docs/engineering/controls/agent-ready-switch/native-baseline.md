# Native baseline evidence

The installed button and switch templates compiled and passed the Native sample's three model tests and strict markup check. An automation-enabled macOS app rendered a nonblank frame. A pointer-style button press changed the displayed saved state; a switch action changed its accessible value from on to off and removed the dependent date. The run reported no dispatch errors.

The observed switch widget bounds were 32 × 19, whereas the Web switch track is 52 × 32. The existing Native template does not consume the matching dimensions from the shared token register. The current renderer's default track calculation also limits the height independently of the frame. A frame-size change alone therefore does not establish visual parity.

This is a baseline for the existing Native templates, not evidence of a new shared behavior runtime, identical motion, all Native controls, another operating system or a live product. Keep the cross-renderer item pending until the implementation and appearance are verified together.
