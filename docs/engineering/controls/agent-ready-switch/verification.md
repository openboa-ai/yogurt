# Switch replacement evidence

The 320 px dark and 1440 px light resting guide captures matched the prior captures byte for byte. The motion gallery check exercised the switch's dimensions, thumb position, rapid reversal and stretch. Installed Vite and Next.js consumers exercised controlled agent changes, policy refusal, disabled state, form data and reset.

The existing native button and switch templates passed installation, three native fixture tests, strict markup checking and a local baseline render using Native SDK 0.11.1. The current native switch geometry differs from the Web design; this does not establish native parity or device performance.
