## Requirements

- **I02-U02A.** Keep the company line “Every limit has a shelf life.” and the three maintained repository descriptions in their intended contexts. UI copy names the object, condition and supported next action.

**Constraint.** Write public and UI copy in English. The product owns observed state and allowed recovery. The brand owner owns company wording, naming and additions to the terms list.

**Design alternative to rule out.** A clever error says the work is done because the button was pressed. An invented food pun makes a repository description harder to understand.
