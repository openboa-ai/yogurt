# I02 · Know what happened and what to do next

Status: DRAFT, revision 1. Decision owner: OpenBoa design-system owner with the language and naming maintainer. Source: [product intent, revision 1](../../../intent.md). [Paired specification](spec.md) · [Recognize the same company across surfaces](../../../journeys/J1/README.md).

## Need

An editor needs a short company introduction, a project description and a message following a lost acknowledgement. The writing should sound like one company while allowing the user to act on the actual facts.

## Success and counterexample

**Success.** Read the three project descriptions beside their food names. In a separate interrupted action, a reader can say what was sent, what remains unknown and where to check.

**Convincing failure.** A clever error says the work is done because the button was pressed. An invented food pun makes a repository description harder to understand.

## Limits

Write public and UI copy in English. The product owns observed state and allowed recovery. The brand owner owns company wording, naming and additions to the terms list.
