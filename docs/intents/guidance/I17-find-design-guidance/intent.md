# I17 · Find the same answer as a designer, engineer or agent

Status: DRAFT, revision 1. Decision owner: OpenBoa design-system owner with the guide and authoring maintainer. Source: [product intent, revision 1](../../../intent.md). [Paired specification](spec.md) · [Adopt a shared component and roll back](../../../journeys/J4/README.md).

## Need

A new contributor has a task description and a target. They need one place to find the right pattern, its copy, working entry or known gap and an example to run.

## Success and counterexample

**Success.** A reader beginning in the web guide and an agent beginning at DESIGN.md select the same pattern and revision for a Sourdough inspection and a Meatball pending receipt.

**Convincing failure.** The guide showcases a polished concept under a shipping badge, or an agent uses unpinned current guidance with an older library.

## Limits

Yogurt owns maintained guidance and catalog IDs. The optional skill and any Figma representation read the same contract. The project owns its design brief and chosen pin.
