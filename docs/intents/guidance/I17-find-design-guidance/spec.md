## Requirements

- **I17-U17A.** Index each stable component or pattern by task, parts, permitted inputs, states, copy, keyboard behavior, recovery, evidence and target availability. The guide and agent entry reference one catalog. A future Figma component may map its name/variant to the same ID.

**Constraint.** Yogurt owns maintained guidance and catalog IDs. The optional skill and any Figma representation read the same contract. The project owns its design brief and chosen pin.

**Design alternative to rule out.** The guide showcases a polished concept under a shipping badge, or an agent uses unpinned current guidance with an older library.
