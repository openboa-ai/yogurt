First family study

A food emoji identifies a project in a list, message or release note. Each drawing has one feature you can name from memory. A peeled lid identifies yogurt. One long score identifies sourdough. Three flecks of cracked pepper finish the round meatball.

Build another member

Choose a food with a distinctive outline. Draw one identifying detail in a few flat shapes on a 64-unit canvas. Pick named values from the shared palette. Place one shallow notch on a calm stretch of the outer contour. Compare the silhouette beside the other foods at message size.

Use :yogurt:, :sourdough: or :meatball: as the suggested custom emoji name. When the adjacent text already names the project, the image can be decorative. When the image stands alone, give it the project name as its accessible label.
