Classify the failure from its reproduction. Route a product fact or permission error to the product. Route a defect reproduced in the installed shared control to Yogurt. Compare consumer examples before proposing a shared preset.

Prepare a portable report with the affected pin, renderer, stable ID, steps, expected and observed result and a checkable fix. Send only shareable facts. For a draft or delegated filing, use the [report contract](references/issue-report.md). The host broker verifies authority, matches existing issues and reconciles writes. Preserve its observed status and issue URL.
