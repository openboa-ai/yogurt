# Design sources

This directory owns the shared visual and language decisions.

| Area | Edit here | Output |
| --- | --- | --- |
| Artwork and type | [Assets](assets/README.md) | Original marks, glyphs, agent artwork and font files |
| Color and UI roles | [Palette](tokens/brand.json) and [UI tokens](tokens/ui.json) | Brand CSS, Web roles and the Native theme |
| Product language | [Terms](content/terms.json) | Preferred words, phrases and guidance |
| Web styling | [Styles](styles/) | Shared surfaces, type, layout and motion |

Read the [design rules](../DESIGN.md) before changing a shared decision. Use the [maintainer commands](../scripts/README.md) to regenerate and check outputs. Component behavior and rendering live in the [SDK packages](../packages/README.md).
